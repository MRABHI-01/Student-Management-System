# Student Management System

## Description
A Java console-based Student Management System developed using Object-Oriented Programming concepts. The project allows users to manage student records efficiently.

## Features
- Add Student
- Display Students
- Search by ID
- Search by Name
- Search by Course
- Update Student
- Delete Student
- Sort by ID
- Sort by Name
- Student Statistics
- File Save & Load
- Automatic Data Saving
- Input Validation
- Exception Handling

## Technologies Used
- Java
- OOP
- Collections (ArrayList, HashMap)
- File Handling
- Git & GitHub

## Project Structure
```
src
├── app
│   └── Main.java
├── model
│   └── Student.java
├── service
│   └── StudentManager.java
└── util
    ├── FileManager.java
    └── InputValidator.java
```

## How to Run
1. Clone the repository.
2. Open in Eclipse or IntelliJ IDEA.
3. Run `Main.java`.
